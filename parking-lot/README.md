# Parking Lot

Cross-project ideas that aren't ready to become projects or FRs yet, but shouldn't be lost. Each idea has a stable `IDEA-NNNN` ID, status, and tags so it can be searched, clustered, and synthesized into patterns.

## Lifecycle

```
parked  ──promote──▶  active FR or new project (status: promoted)
   │
   ├──cluster──▶  proposed PATTERN (status: merged-into-pattern)
   │
   └──no longer relevant──▶  archived (status: archived, with reason)
```

## When to add an idea

Use `/park <idea>` from any Cowork session. The slash command captures the idea, auto-tags it, asks for a value hypothesis, and writes the file. Do not write IDEA files by hand — the IDs are allocated by `scripts/parking.py` and need to stay sequential.

## Reflection cadence

`scripts/parking.py reflect` flags any idea with `last_reviewed` older than 90 days. Run it weekly (or invoke `/cos --reflect`) to either re-validate, archive, or promote the stale ones. Without this, the parking lot becomes a graveyard.

## Linking back to projects

When `/promote IDEA-NNNN` succeeds, the idea's frontmatter gains `promoted_to: <project>/FR-NNNN`, and the new FR's frontmatter gains `derived_from: IDEA-NNNN`. The link is bidirectional and preserved through both records' lifetime.

## Index

`INDEX.md` is auto-generated by `scripts/parking.py reindex`. Do not edit by hand.
