# Hub

This directory holds workspace-level state that crosses projects:

- **`projects.yaml`** — registry of every project bootstrapped from this hub. Maintained by `scripts/bootstrap.py`.
- **`FR-INDEX.json`** — denormalized cross-project FR data, regenerated by `scripts/hub-index.py`. The Chief of Staff slash command and pattern detector query this rather than walking every project's `specs/` directory.
- **`PATTERN-INDEX.md`** — human-readable catalog of accepted/proposed patterns. Auto-generated.

## Refreshing the indexes

```
python scripts/hub-index.py
python scripts/parking.py reindex
python scripts/patterns.py reindex
```

The hub-level slash commands (`/cos`, `/patterns`) refresh these automatically before reading them, so manual reindex is rarely needed.
